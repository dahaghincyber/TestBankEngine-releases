# بانک تست کنکور هنر

نرمافزار دسکتاپ مدیریت سؤالات کنکور هنر — از فایل PDF تا آزمون آماده.

## دانلود

**[دانلود آخرین نسخه](https://github.com/dahaghincyber/TestBankEngine-releases/releases/latest)**

فایل `TestBankEngine-Setup-vX.Y.Z.exe` را دانلود کنید.

## نصب

1. فایل installer را دانلود کنید.
2. دوبار کلیک کنید. نیازی به دسترسی administrator نیست.
3. پس از نصب، «بانک تست» در منوی Start ظاهر میشود.

## حذف

`Settings → Apps → بانک تست → Uninstall`

از نسخهٔ 2.6.5 به بعد، پایگاه دادهٔ شما در `%APPDATA%\TestBankEngine\` ذخیره میشود و با حذف نرمافزار پاک نمیشود.

## نیازمندیها

- Windows 10 یا 11
- حداقل ۴ گیگابایت RAM
- (اختیاری) کارت گرافیک NVIDIA برای قابلیتهای هوش مصنوعی محلی

## قابلیتها

- ورود PDF آزمونها و استخراج خودکار سؤالات
- برچسبگذاری خودکار به ۳۵ کتاب مرجع کنکور هنر
- دستهبندی موضوعی: ریاضی، هندسه، هوش، فیزیک، ترسیم فنی
- صف بازبینی با پشتیبانی از تصاویر
- آزمونساز با خروجی Word
- بهروزرسانی خودکار
